# Bansong Classroom
เว็บไซต์ห้องเรียนคอมพิวเตอร์ เขียนด้วย Astro, TypeScript และ CSS รองรับชั้น ป.1–ป.6 เริ่มตัวอย่างที่ ป.4–ป.5

## เปิดในเครื่อง
```
npm install
npm run dev
```
## สร้างไฟล์เผยแพร่
```
npm run build
```
ผลลัพธ์อยู่ใน `dist/` ใช้กับ Cloudflare Pages: build command `npm run build`, output directory `dist`.

## เพิ่มบทเรียน
สร้างไฟล์ `.md` ใน `src/content/lessons/` โดยคัดลอกหัวข้อมูลจากบทเดิม แต่ละบทกำหนด title, grade, order, description, icon, duration, objectives ได้ ระบบสร้างหน้าและเรียงบทเรียนอัตโนมัติ

แก้รายการชั้นใน `src/data/grades.ts` และเปลี่ยน `ready` ให้เป็น true เมื่อเตรียมบทเรียนพร้อมแล้ว ปัจจุบันแสดง ป.1–ป.6 และขยายรายการได้

## ใบงาน
ยังไม่ได้แนบใบงานจริง จึงแสดงสถานะกำลังเตรียม ไม่มีลิงก์ดาวน์โหลดจำลอง วางไฟล์จริงใน `public/downloads/` แล้วเพิ่มลิงก์ใน Markdown เช่น `[ดาวน์โหลดใบงาน](/downloads/p5-lesson1.docx)` และปรับหน้ารวมใบงานให้ตรงกับไฟล์ที่เพิ่ม

เนื้อหาที่ให้มาเป็นตัวอย่างสำหรับตรวจรูปแบบ ครูควรตรวจและปรับให้ตรงแผนการสอนก่อนใช้จริง ชื่อครูและข้อมูลติดต่อยังไม่ถูกเพิ่ม
